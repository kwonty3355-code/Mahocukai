# 마호츠카이 (가제) — 게임 기획서

> 인터뷰(2026-11-23) 결과 정리. 정해지지 않은 항목은 **[미정]** 으로 표시.

## 1. 만든 이유 (가장 중요한 원칙)

애니·특촬물을 볼 때 "손이 놀고 있으면 뭔가 해야 할 것 같은" 강박이 있다.
그런데 볼 때는 감정선을 온전히 따라가며 몰입하고 싶다.
웹툰은 스크롤로 손이 바쁘니까 괜찮고, **영상만** 문제다.

이 게임은 그 강박을 억누르지 않고, **생각이 필요 없는 손 작업**으로 흘려보내는 장치다.
동시에, 영상을 보지 않을 때는 그 작업의 결과물로 **이펙트·타격감·간지에 모든 걸 쏟은 전투**를 즐긴다.

### 몰입 보호 규칙 (손 작업에 반드시 적용)
손 작업 중에는 아래 요소가 **하나도** 없어야 한다. 생각이 드는 순간 몰입이 깨진다.

| 금지 | 예시 |
|---|---|
| 선택 | "뭘 만들지?" 같은 고르기 |
| 확인 | 숫자 팝업, 진행도, 알림, 화면을 봐야 하는 순간 |
| 실패 | 삐뚤어짐 판정, 실패 효과음 |
| 새로움 | 처음 보는 연출, 깜짝 이벤트 |
| 목표 | "이번 화 안에 몇 개" 같은 할당량 |

- 결과는 작업을 **마칠 때 한 번에** 보여준다.
- "시청 모드"라고 티 내지 않는다. 게임 안의 평범한 공방 작업처럼 보여야 한다.
- 검은 화면은 금지. 방치형 게임처럼 보이기 때문이다. 잔잔하게 살아 있는 작업대 화면을 보여준다(촛불, 날씨, 쌓여가는 결과물).

## 2. 게임 흐름

```
[원석 정제 작업]   생각 없이 돌리는 손 작업 → 여러 재료 획득 (가장 효율 좋은 재료 수급처)
        ↓
[공방]            마법진 설계(칸 배치) → 반투명 가이드 따라 그리기 → 완성도 판정
                  → 스크롤(소모품)에 새기거나 마법봉(영구)에 각인
        ↓
[전투]            스크롤·마법봉 사용 → 마법진을 불러오는 시간 → 발동
                  (마법진이 클수록 불러오는 시간이 길고 강함)
        ↓
[자격증 승급]      승급 시험 = 보스전 → 새 원소·문양 해금
```

## 3. 원석 정제 작업 (손 작업)

- 작업 전에 정제할 원석 묶음을 넣는다. 작업 중에는 아무것도 고르지 않는다.
- 돌리는 동작 하나로 진행된다. 결과물: 원소 가루(불·물·바람·땅), 잉크 원액, 양피지 섬유, 가끔 희귀 결정.
- 재료는 전투에서도 얻을 수 있지만, 이 작업이 **훨씬 효율적**이다.
- **[미정]** 작업 연출: 맷돌, 물레, 가마솥 중 무엇으로 할지, 또는 섞을지는 시제품에서 정한다.
- **[미정]** 아이패드용 피드백 소리: 시제품에서 켜고 끄며 정한다.

### 입력 방식 (모두 같은 "돌리기" 동작으로 취급)
| 기기 | 입력 | 비고 |
|---|---|---|
| 아이패드 | 손가락으로 원 그리기 | 진동 없음 → 피드백 소리 검토 |
| 컨트롤러 | 스틱 돌리기 | 한 바퀴마다 약한 진동. 집에 GW01 패드 있음, 아직 테스트 전 |
| PC | 마우스 휠 | 휠의 물리적인 걸림이 촉감 피드백 |

- **스틱 마모 대비**: 가장자리까지 밀지 않은 작은 원도 인정한다. 버튼 리듬이나 양쪽 스틱 번갈아 쓰기도 같은 작업으로 인정해서 마모를 분산한다.

### 기기 구성
- 주 사용: **영상은 PC, 손 작업은 아이패드**
- 보조: 영상은 아이패드, 손 작업은 PC(컨트롤러나 휠)
- 제외: 한 기기에서 PiP, 전용 데스크톱 앱
- 이유: 브라우저는 앞에 떠 있는 창에서만 입력을 받는다.

## 4. 공방 (집중 콘텐츠)

- **마법진 조합: 칸 배치형.** 마법진 안에 중심·고리·바깥 같은 칸이 있고, 원소·형태·수식 문양을 끼워 넣는다.
  - 원소(시작): 불, 물, 바람, 땅. 승급하면 번개·얼음·빛·어둠 등이 해금된다.
  - 형태 예시: 투사, 소환, 장판, 결계
  - 수식 예시: 연쇄, 확산, 지연, 관통
- **그리기**: 완성될 마법진을 반투명 가이드로 보여주고, 그걸 따라 그린다. 정확도(완성도)가 위력 등을 결정한다.
- **그리기 도구**: 애플 펜슬, 아이패드 손가락, PC 마우스, PC 펜 태블릿 **모두 지원**한다. 펜 압력은 지원하는 기기에서만 쓴다.
- **마법진 크기**: 그릴 때 정한다. 전투에서 크기는 곧 불러오는 시간이자 위력이다.
- **스크롤**: 1회용 소모품. 강력한 비장의 수.
- **마법봉**: 영구 장비. 각인 칸 수에 제한이 있다. 다시 그려서 완성도를 올리는 재미가 있다.

## 5. 전투 (영상 안 볼 때)

- 캐릭터 모델링과 전장은 최소한으로, **이펙트·타격감·간지에 전부 투자**한다.
- **이펙트 스타일: 혼합.** 빛과 파티클은 3D처럼 부드럽게, 맞는 순간에만 2D 애니처럼 임팩트 프레임과 집중선으로 끊는다.
  - 참고 시연: 이펙트 비교 페이지 (`prototypes/effect-demo.html`)
- 타격감 요소: 히트스톱, 화면 흔들림, 카메라 펀치 줌, 섬광, 임팩트 프레임, 집중선, 충격파, 파티클, 데미지 숫자, 효과음, 컨트롤러 진동
- 번쩍임 줄이기 옵션을 반드시 넣는다.
- **전투 방식**: 9×9 전략 턴제로 확정 (8장 참고).

## 6. 진행 구조

- **스토리는 거의 없음.** 게임이 무거워지지 않게, 세계관은 아이템 설명과 자격증 시험 이름 정도로만 은은하게 남긴다.
- **자격증 승급**은 성장 단계 표시와 해금 수단으로 유지한다. 승급 시험이 보스전이다.

## 7. 플랫폼과 기술 요구사항

- 웹 게임. 아이패드에서는 홈 화면에 앱처럼 설치(PWA)
- PC(크롬 계열)와 아이패드(사파리) 모두 지원
- **세이브 자동 동기화**: PC와 아이패드가 같은 진행을 공유한다. 간단한 로그인과 클라우드 저장이 필요하다.
- 컨트롤러: Gamepad API. 진동은 PC 크롬에서만 기대한다.

## 8. 2차 인터뷰 결정 (2026-11-23)

### 집중도별 4가지 모드 (같은 재료와 성장을 공유)
| 모드 | 주의력 | 내용 |
|---|---|---|
| 방치 | 0% (만화·웹툰) | 켜두면 알아서 진행. 웹툰은 강박이 없으므로 보너스 성격 |
| 손 작업 | 손만 (애니 몰입) | 원석 정제 작업대 |
| 반반 라이브 | 50% (방송 등) | 무한런. 가끔 선택하고, 가끔 희귀 변이(이로치)가 등장하는 도파민 |
| 레전드 집중 | 100% | 9×9 전략 턴제 로그라이크 |

### 집중 모드 전투
- 9×9 격자 전략 턴제. 매 판이 전략적으로 재밌는 것이 최우선이다.
- 마법사 1명 + 사역마. 사역마는 **패시브형**과 **같이 싸우는 전투형**이 있다.
- 큰 마법진은 여러 턴 영창한다. 영창 중인 마법사를 사역마가 지키는 구조.
- **적 예고는 일부만** 공개한다. 누구를 노리는지는 보이지만 공격 종류와 위력은 숨긴다. 정보를 더 보여주는 사역마를 넣어 정보 자체를 전략 요소로 만든다.
- **원소 반응 많이.** 칸에 원소가 남고 서로 반응해 연쇄된다 (예: 바람이 불을 퍼뜨림, 물+땅은 진흙, 불+물은 증기로 시야 차단, 땅은 벽).
- **로그라이크**: 공방에서 그린 마법봉 각인과 스크롤을 들고 들어간다. 런 안에서 임시 문양, 스크롤, 사역마를 얻는다.
- **제약 도전**: 제약을 걸고 들어가 지키면 점수 배율과 보상이 올라간다. 기록 갱신.

### 뽑기
- 대상은 **사역마**. 현금 결제 없음, 게임 재화로만 뽑는다.
- 천장 있음 (시연: 60회에 오로라 확정).
- **뽑기 레벨 같은 해금 구조 없음.** 중복은 **돌파** (최대 5단계, 적당한 효과). 사역마 개별 레벨업은 없음.
- 표현: **종이 오리기 실루엣.** 희귀도는 종이 재질 (일반 색종이 → 금박 → 오로라 홀로그램). 이로치는 남색 종이 + 은박 + 낙관 도장.
- 소환 연출: 마법진 색으로 등급 예고, 오로라는 금색에서 승급하는 반전 연출 있음.
- 시연: `prototypes/paper-familiars.html`

### 아트 방향
- **종이 스탠디 디오라마**: 2.5D 판 위에 받침대에 꽂힌 평면 종이 카드가 서 있다. 맞으면 휘청이고, 쓰러지면 타서 재가 된다.
- **AI풍 금지**: 매끈한 일러스트, 흔한 그라디언트, 과하게 예쁜 디자인을 피한다. 종이 질감, 오리기, 박, 도장처럼 물성 있는 표현을 쓴다.
- **완성도 최우선**: 얇다고 느끼는 순간 그만두게 된다.

### 플랫폼
- 폰, 태블릿, PC 모두 구동.

### 하드웨어 메모
- 사용자 컨트롤러는 홀 이펙트 스틱이라 스틱 돌리기로 인한 센서 마모 걱정이 없다. 진동 모터 있음.
